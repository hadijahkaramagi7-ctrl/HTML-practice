# Web & Console Projects

A collection of beginner-friendly JavaScript projects — web apps and console apps.

## Projects

### 🌐 Web Projects (open `index.html` in a browser)

| Project | Folder | Description |
|---------|--------|-------------|
| Calculator | `calculator/` | A basic calculator with buttons and keyboard support |
| Weather App | `weather-app/` | Fetches live weather using the Open-Meteo API (no API key needed) |
| Quiz App | `quiz-app/` | Multiple-choice quiz with score and progress |
| Expense Tracker | `expense-tracker/` | Add/delete expenses, saved in browser localStorage |

### 💻 Console Projects (run with Node.js)

| Project | File | How to run |
|---------|------|------------|
| Number Guessing Game | `number-guessing/number_guessing.js` | `node number_guessing.js` |
| Hangman | `hangman/hangman.js` | `node hangman.js` |

## How to Run

**Web projects:** Open the `index.html` file in your browser.  
**Console projects:** Open a terminal and run `node <filename>.js`.

## Technologies

- HTML5, CSS3, JavaScript (vanilla)
- Node.js (for console apps)
- Open-Meteo API (free, no key required)
